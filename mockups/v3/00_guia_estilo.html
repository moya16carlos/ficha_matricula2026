Sistema visual «Institucional claro»

Un solo idioma visual para toda la intranet: fondo claro, indigo como color único, jerarquía tipográfica consistente y componentes repetibles. Reemplaza la mezcla actual (login morado animado + navbar oscuro + botones heterogéneos).

1 tipografía
Inter (hoy: Poppins + Inter mezcladas)
1 color acción
Indigo = botones y enlaces; rojo/ámbar solo semántico
Navbar claro
Blanco con borde; contenido respira (antes oscuro)
Todo CLI=0
Estados visibles: activo, prov., retirado, guardado
